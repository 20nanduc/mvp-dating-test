# MVP-DATING
### Less swiping. More meaningful conversations.

**MVP-DATING** is a mobile-first dating application built to explore a simple question:

**Can two people build a more meaningful connection when conversations revolve around one shared thought at a time, instead of endless profile browsing and unstructured small talk?**

### The Problem

Traditional dating applications often emphasize discovering more people, but connecting with someone does not guarantee a meaningful conversation.

MVP-DATING explores a different approach: **mutual curiosity, intentional interactions, and thought-centered conversations.**

### Our Goal

Build an alternative dating experience where people connect through curiosity and develop relationships by exploring shared thoughts.

Instead of introducing complex matchmaking algorithms, the MVP focuses on validating three fundamental ideas:

1. **Curiosity before connection:** Users express genuine interest before entering a private conversation.
2. **Conversation with context:** Every connection revolves around one active thought, giving both participants a clear starting point.
3. **Intentional progression:** Participants can propose and explore new thoughts together rather than relying on endless, unstructured messages.

### Current Status

🚀 **Launched — Early User Testing**

The application has been developed, deployed, and made available for initial testing.

The next phase focuses on understanding user behavior, identifying friction, and validating whether thought-centered conversations create a more engaging dating experience.
